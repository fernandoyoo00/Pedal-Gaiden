PedalGaiden Boost Animation Pack

Four transparent RGBA PNG frames per ninja (oni, fire, poison, ice).
Each is based directly on the uploaded original artwork, preserving the original rider and bicycle.
Animation uses subtle bobbing plus evolving boost streaks and particles.
The rider legs are NOT independently redrawn; this is a boost-effect loop, not a full pedalling cycle.
Four-frame horizontal sprite sheets are included.
Frame duration suggestion: 80-120 ms; repeat loop.
Use Nearest filtering for pixel-art sprites in libGDX.
